# קטיפה

אפליקציית סלולר (PWA) לערב זוגי: חפיסת משימות עם איורים, קוביות, טיימר, הגדרת גבולות לכל אחד בנפרד, ומילת עצירה שעוצרת הכול. לשימוש אישי של שני בני זוג בוגרים.

הכול נשמר במכשיר בלבד (localStorage). אין שרת, אין חשבון, שום דבר לא נשלח לשום מקום.

## מה יש בפנים
- **הגדרה ראשונית** – הסכמה, שמות ומין של שניכם (הטקסטים מוטים לפי מין המוביל/ה והמובל/ת), מי מוביל, מילת עצירה.
- **גבולות** – כל אחד מסמן לבד, במסך "מסור/י את הטלפון", לכל קטגוריה: כן / אולי / לא, ועוצמה מרבית 1–3. במשחק נכנס רק החיתוך של שניכם, ולא מוצג מי סימן מה.
- **ערב** – חפיסה של 11 משימות שעולות בהדרגה מעוצמה 1 ל-3, ובסוף תמיד כרטיס "אחרי". בוצע / דילוג / מועדף / לא שוב. טיימר בתוך הכרטיס.
- **קלף אקראי**, **קוביות** (פעולה × איבר × משך) ו**טיימר** עצמאי.
- **עצור** – כפתור אדום בכל מסך משחק. מציג את מילת העצירה ומאפשר מעבר ישיר ל"אחרי".
- **החפיסה** – 73 משימות מובנות ב-10 קטגוריות + 3 כרטיסי "אחרי", עורך להוספת כרטיסים משלכם עם בחירת איור, מועדפים והסתרה.
- **קוד נעילה** (4 ספרות), מסך דולק בזמן משחק, מחיקת כל הנתונים בלחיצה.
- **בטיחות** – עמוד עם מה כן ומה בשום אופן לא. משחקי נשימה וחניקה לא נכללים בכוונה.

## תחביר הכרטיסים
`{D}` שם המוביל/ה, `{S}` שם המובל/ת, `{d:זכר|נקבה}` לפי מין המוביל/ה, `{s:זכר|נקבה}` לפי מין המובל/ת.
דוגמה: `{d:קשור|קשרי} את הידיים של {S}. {s:הוא|היא} לא {s:זז|זזה}.`

## התקנה על הטלפון
1. פתחו את כתובת האתר בדפדפן הטלפון (Safari באייפון, Chrome באנדרואיד).
2. אייפון: שיתוף ← "הוסף למסך הבית". אנדרואיד: תפריט ⋮ ← "הוסף למסך הבית".
3. מומלץ להפעיל קוד נעילה ב"עוד".

## פרסום (GitHub Pages)
הענף הזה עצמאי (orphan). כדי להעביר אותו לרפו משלו:
```bash
git clone --branch claude/ktifa-app --single-branch https://github.com/dudutal-dev/Butbul ktifa
cd ktifa
git branch -m main
git remote set-url origin https://github.com/<user>/<new-private-repo>.git
git push -u origin main
```
ואז ברפו החדש: Settings ← Pages ← Source: **GitHub Actions**. ה-workflow יפרסם בכל דחיפה ל-`main`.
הכתובת תהיה `https://<user>.github.io/<repo>/`. ברפו פרטי GitHub Pages דורש חשבון Pro; לחלופין אפשר להעלות את התיקייה ל-Netlify Drop או Cloudflare Pages.

## הרצה מקומית
```bash
python3 -m http.server 8000
```
ולפתוח `http://localhost:8000`.

## מבנה
- `index.html` – כל המסכים.
- `css/style.css` – עיצוב.
- `js/app.js` – ניווט, הגדרות, גבולות, ערב, קוביות, טיימר, עורך, נעילה.
- `js/cards-data.js` – קטגוריות, חפיסת המשימות, קוביות.
- `js/illustrations.js` – איורי SVG (ספרייט) לכרטיסים ולקטגוריות.
