# קטיפה

אפליקציית סלולר (PWA) לערב זוגי: חפיסת משימות עם איורים, קוביות, טיימר, הגדרת גבולות לכל אחד בנפרד, ומילת עצירה שעוצרת הכול. לשימוש אישי של שני בני זוג בוגרים.

הכול נשמר במכשיר בלבד (localStorage). אין שרת, אין חשבון, שום דבר לא נשלח לשום מקום.

## מה יש בפנים
- **הגדרה ראשונית** – הסכמה, שמות ומין של שניכם (הטקסטים מוטים לפי מין המוביל/ה והמובל/ת), מי מוביל ואיך: קבוע כל הערב, מתחלף כל משימה, או הגרלה בכל ערב (מגרילה גם מי מוביל וגם קבוע/מתחלף). מילת עצירה.
- **גבולות** – כל אחד מסמן לבד, במסך "מסור/י את הטלפון", לכל קטגוריה: כן / אולי / לא, ועוצמה מרבית 1–3. במשחק נכנס רק החיתוך של שניכם, ולא מוצג מי סימן מה.
- **ערב** – חפיסה של 11 משימות שעולות בהדרגה מעוצמה 1 ל-3, ובסוף תמיד כרטיס "אחרי". בוצע / דילוג / מועדף / לא שוב. טיימר בתוך הכרטיס.
- **קלף אקראי**, **קוביות** (פעולה × איבר × משך) ו**טיימר** עצמאי.
- **עצור** – כפתור אדום בכל מסך משחק. מציג את מילת העצירה ומאפשר מעבר ישיר ל"אחרי".
- **החפיסה** – 104 משימות מובנות ב-15 קטגוריות + 3 כרטיסי "אחרי", עורך להוספת כרטיסים משלכם עם בחירת איור, מועדפים והסתרה.
- **תמונות וסרטונים שלכם** – ב״עוד ← כל המשימות לפי קטגוריות״: רשימה של כל המשימות, כולל אלה שהוספתם, עם חריץ תמונה וארבעה חריצי סרטון לכל אחת: **סרטון אישי** ו**הדגמה**, ולכל סוג סרטון לערב שבו א׳ מוביל/ה וסרטון לערב שבו ב׳ מוביל/ה. בכרטיס מוצג הסרטון של מי שמוביל/ה הערב (ואם אין, השני), ואם יש גם אישי וגם הדגמה מופיע בורר על הכרטיס. אם יש גם תמונה, שניהם מוצגים; אם אין כלום, האיור. תמונות מוקטנות אוטומטית; סרטונים נשמרים כמו שהם ומתנגנים אוטומטית בלי קול. **תמונת פרופיל** לכל בן/בת זוג מופיעה בדף הבית ובכרטיסים. הכול ב-IndexedDB במכשיר בלבד, בלי גיבוי.
- **איורים ב-AI** – מתוך טופס כרטיס חדש: ״✨ איור ב-AI״. Claude (ברירת מחדל `claude-opus-5-5`, דרך ה-SDK הרשמי שנטען מ-esm.sh) מצייר איור SVG חדש בסגנון הקווים של האפליקציה לפי התיאור שלכם. דורש מפתח API של Anthropic שנשמר רק בטלפון. התוצאה עוברת סינון (רק צורות, בלי סקריפטים או צבעים זרים) ונשמרת כאיור שאפשר לבחור לכל כרטיס.
- **קאסט לטלוויזיה (16:9)** – "עוד ← קאסט לטלוויזיה" או 📺 מתוך כרטיס. האפליקציה עוברת לבמה 16:9 עם איור ענק, טקסט גדול, קוביות וטיימר, ומנסה לנעול את המסך לרוחב. בכל טלפון: שיקוף מסך (AirPlay באייפון, Smart View / Cast באנדרואיד) מציג את הבמה בדיוק בגודל הטלוויזיה. ב-Chrome אנדרואיד/מחשב עם Chromecast יש גם כפתור 📡 שפותח את האפליקציה על המכשיר (אותה כתובת עם `?tv=1`) ומשדר אליו את הכרטיס הנוכחי.
- **מתקדם** – קבוצה נפרדת במסך הגבולות, עם אותם כללים כמו שאר הקטגוריות (״לא״ של אחד מוציא, ״אולי״ נכנס עם ״לכלול אולי״): **יד על הצוואר** (מחווה בלבד, בלי לחץ שמפריע לנשימה או לזרימת הדם), **נוזלים** (יריקה והשתנה) ו**משחקי זרע**.
- **כל המשימות להעתקה** – ב״עוד״: כל משימה פעמיים, ״הגבר מוביל״ ו״האשה מובילה״, בלי שמות, עם כפתור העתקה לכל נוסח, לכל קטגוריה ולהכול.
- **הקראת כרטיסים** – כפתור 🔊 בכרטיס. קול הדפדפן (חינם, אופליין) או ElevenLabs עם מפתח API ו-Voice ID משלכם (מודל `eleven_v3` תומך בעברית). הקלטות נשמרות במכשיר כדי לא לשלם פעמיים על אותו כרטיס.
- **הערות בטיחות על הכרטיסים** כבויות כברירת מחדל, אפשר להדליק ב״עוד״. עמוד הבטיחות והערות הקטגוריות במסך הגבולות נשארים.
- **רענון לגרסה החדשה** ב״עוד״: מוריד את הגרסה העדכנית בלי להסיר את האפליקציה ובלי לאבד נתונים. מספר הגרסה מופיע בתחתית ״עוד״. כשגרסה חדשה יורדת ברקע מופיע פס ״רענון״.
- **קוד נעילה** (4 ספרות), מסך דולק בזמן משחק, מחיקת כל הנתונים בלחיצה.
- **בטיחות** – עמוד עם מה כן ומה בשום אופן לא. משחקי נשימה וחניקה לא נכללים בכוונה.

## תחביר הכרטיסים
`{D}` שם המוביל/ה, `{S}` שם המובל/ת, `{d:זכר|נקבה}` לפי מין המוביל/ה, `{s:זכר|נקבה}` לפי מין המובל/ת. אפשר לקנן: `{d:גמור {s:לו|לה} בפה|תני ל{S} לגמור}`.
דוגמה: `{d:קשור|קשרי} את הידיים של {S}. {s:הוא|היא} לא {s:זז|זזה}.`

## התקנה על הטלפון
1. פתחו את כתובת האתר בדפדפן הטלפון (Safari באייפון, Chrome באנדרואיד).
2. אייפון: שיתוף ← "הוסף למסך הבית". אנדרואיד: תפריט ⋮ ← "הוסף למסך הבית".
3. מומלץ להפעיל קוד נעילה ב"עוד".

## הרצה מקומית
```bash
python3 -m http.server 8000
```
ולפתוח `http://localhost:8000`.

## מבנה
- `index.html` – כל המסכים.
- `css/style.css` – עיצוב.
- `js/app.js` – ניווט, הגדרות, גבולות, ערב, קוביות, טיימר, עורך, נעילה.
- `js/cards-data.js` – קטגוריות, חפיסת המשימות, קוביות.
- `js/illustrations.js` – איורי SVG (ספרייט) לכרטיסים ולקטגוריות.
- `js/media.js` – שמירת תמונות, סרטונים, פרופילים והקלטות ב-IndexedDB.
